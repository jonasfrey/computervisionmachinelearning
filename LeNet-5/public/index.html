About this implementation

The feature extractor follows LeNet-5: sparse C3 connectivity, learnable average subsampling, and scaled tanh. This teaching variant uses [−1, 1] input normalization and a dense + softmax output instead of the original Euclidean RBF head. All 60,850 parameters are initialized, not trained. Example digits are drawings, not MNIST samples. Training and pretrained weights are future work.
